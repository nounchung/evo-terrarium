# R9.1 Validation

Status: technical implementation checkpoint complete; browser visual and performance gate blocked

Issue: [#19 — Living Diorama terrain and light technical spike](https://github.com/nounchung/evo-terrarium/issues/19)

## Implemented scope

- Living Diorama terrain is the default renderer.
- `?terrain=classic` preserves the R8 renderer for same-seed A/B comparison.
- Biome cells use deterministic tonal variation derived only from grid coordinates and biome state.
- Meadow and grass receive distinct ground detail; forest receives layered canopy clusters; water receives bounded ripple detail.
- Water/land boundaries receive a dedicated shadow, sand and highlight shoreline treatment.
- Other biome boundaries receive a softer transition band.
- Terrain is still rebuilt only when `terrainRevision` changes.
- Canvas data exposes `data-terrain-style`, `data-terrain-revision`, `data-terrain-build-ms` and rolling `data-fps`.
- Unit coverage proves deterministic visual sampling, style selection, water classification and colour mixing.
- Playwright coverage is prepared for default/classic mode, metrics exposure and terrain-revision updates after painting.
